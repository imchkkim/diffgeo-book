보강 작업의 **유일한 기준**. 수식 색, 등장인물, 대화 규칙은 여기만 고친다. 위젯 색 값은 `viz/shared/palette.js` 가 이 표를 따른다.

## 1. 수식 표기: 색과 기호 표

### 규칙 (사용자 지시 원문)

> 수식을 처음 만나는 독자의 부담을 줄이기 위해, 모든 display 수식은 다음 형식을 따른다. 앞으로 만드는 JSX 인터랙티브 위젯도 같은 기호에 같은 색(아래 hex)을 쓴다.
> 1. 수식 안의 기호만 \textcolor{색}{기호}로 칠한다. 괄호, 연산자, 숫자는 기본 글자색. \color는 뒤따르는 것까지 칠하므로 쓰지 않는다.
> 2. 수식 바로 아래에 기호 표를 latex array로 단다. 기호는 같은 색, 설명은 기본 글자색(\text{}). 문서 표는 글자색을 지원하지 않아 array를 쓴다.
> 3. 핵심 기호는 책 전체에서 아래 색을 고정한다. 색은 글자가 아니라 개념에 배정한다. 같은 글자가 다른 개념이면 다른 색이고, 기호 표에 그 식에서의 뜻을 적는다(예: H가 엔트로피인지 해밀토니안인지).
> 4. 그 절에서만 쓰는 보조 기호(m, g, t, Δt, ε, η, ω, l, σ, 상수 계수 등)는 기본 글자색으로 두고 표에 설명만 적는다.
> 5. 새 핵심 기호가 나오면 이 표에 먼저 색을 배정한 뒤 쓴다.

### 형식 예

```latex
$$\textcolor{#9467bd}{\Gamma}^i_{jk} = \frac{1}{2}\textcolor{#d62728}{g}^{il}\left(\partial_k \textcolor{#d62728}{g}_{lj} + \cdots\right)$$

(display 수식은 `$$` 줄 + 수식 + `$$` 줄. 기호 표는 바로 다음 `$$` 블록.)

$$\begin{array}{ll}
\textcolor{#9467bd}{\Gamma}^i_{jk} & \text{크리스토펠 기호 (좌표 보정값)} \\
\textcolor{#d62728}{g}_{ij} & \text{계량 성분}
\end{array}$$
```

첨자·지수에 색을 넣을 때는 중괄호로 감싼다.

### 색 배정표 (확정 2026-09-25)

원고의 `\textcolor` 에는 **light hex** 를 쓴다. 빌드가 CSS 변수(`--c-<키>`)로 바꿔 다크 모드에서 dark 값으로 보인다. 값을 바꿀 때는 이 표와 `viz/shared/palette.json` 을 함께 고친다(위젯은 palette.json 만 읽는다). 대비는 흰 배경·`#1a1a2e` 배경 모두 3:1 이상.

보조 기호(기본 글자색, 표에 설명만): 매개변수 $t$, 구간 $a,b$, 구의 반지름 $R$·$r$, 차원 $n$, 작은 수 $\epsilon,\delta$, 영역 $\Omega$, 면적요소 $dA$, $\omega_n$, 첨자 $i,j,k,l$, 야코비안 $J$, 매니폴드 이름 $M,N$, 1~9장의 점 $p$.

**같은 글자, 다른 개념** — 기호 표에 반드시 뜻을 적는다: `R`(구 반지름 / 리만 곡률 / 스칼라 곡률), `∇`(접속 / 12장 그래디언트 — 그래디언트는 기본색), `F`(가우스 계량 성분 / 피셔 정보 — 둘 다 계량이라 같은 색), `p,q,r`(점 / 확률분포 / 극좌표 반지름), `G`(계량 성분 / 아인슈타인 텐서 / 중력상수), `C`(매끄러움 $C^\infty$ / 3차 텐서 / 바일 텐서).

### 대화 규칙 (원문)

> • 학생끼리는 반말, 선생님께 존댓말. 선생님은 해요체를 쓰고 학생을 "민준 학생", "서연 학생"으로 부른다.
> • 대화 표기는 선생님:, 김민준:, 이서연:
> • 한 문제에서 두 학생은 서로 다른 이유로 틀리거나 한 명만 틀린다.
> • 교정 뒤 일상 비유나 일화 하나. 민준의 비유는 학부생 수준(과제, 보고서, 조교), 서연은 수학 수업에서.
> • 대화 분량은 난이도에 맞춘다. 쉬운 개념은 가볍게, 킬러 문제는 촘촘하게.

### 인물 이미지 자리 (사용자 지시 원문)

> 캐릭터 이미지는 일단 생략. 나중에 고품질 인물별 감정별 이미지 세트를 제공하겠으니 각자 자리만 만들어놓을 것. 한 인물의 대화 차례에 필요한 경우 한 명의 이미지가 들어가는 식으로

- 표정 이미지 원본: `~/dynamics-book/characters/assets/*.svg` (38개, 생성기 `generator.py`·`render.py`, 표정 시트 `sheet.png`). `images/cast/` 에 복사해 쓴다(사용자 지시: "표정 이미지 관련 파일들은 ~/dynamics-book 쪽에서 찾아볼 것"). 원본이 갱신되면 다시 복사.
- 대화는 `<div class="dialogue">` … `</div>` 안에 쓰고(앞뒤 빈 줄 필수), 한 차례 = 한 문단 `**김민준:** 대사`.
- 이미지가 필요한 차례에만 라벨에 표정 인덱스를 붙인다: `**김민준 〔M04〕:** 대사`. 빌드가 그 차례 왼쪽에 `images/cast/M04.png`(.webp/.jpg/.svg)를 넣고, 파일이 없으면 점선 빈 자리를 그린다. 이미지 세트가 오면 파일만 넣으면 된다.
- 인덱스: 선생님 T, 민준 M, 서연 S + 두 자리 번호. 01 평상 / 02 호기심 / 03 궁금함 / 04 난처함 / 05 난제를 만남 / 06 납득이 안 됨 / 07 아하 / 08·09·10 깨달음 1·2·3단 / 11 만족 / 12 장난(비꼬며 씩 웃기), 선생님 13 흐뭇함 / 14 짚어 주기.
- 감정이 크게 움직이는 차례에만(한 문제에 1~3개). 깨달음 3단은 장의 큰 전환점에만.

### 장 구성 (보강 후)

`출발 문제 → 패턴 → 정리 → (따라 계산해 보기) → 정의 → 핵심 인물과 일화 → 직접 움직여 보기 → 연습문제와 같이 풀기 → 연결되는 세계들`

- 따라 계산해 보기: `<div class="worked">`, 장당 1~2개.
- 연습문제와 같이 풀기: 3~4문제. 문제와 풀이 대화를 짝지어 붙인다(사용자 지시: "연습문제와 같이 풀기를 각각 붙여놓자 문제1 - 같이 풀기 세션1, 문제2 - 같이 풀기 세션2 식으로").
  ```
  ### 문제 N — 제목
  <div class="exercises"> <span class="level">확인|계산|킬러</span> 문제 </div>
  #### 같이 풀기 세션 N
  <div class="dialogue"> 대화 </div>
  ```
  대화 속 수식도 색 규칙 동일.
- 모든 수치는 파이썬으로 검증한 뒤 쓴다.
