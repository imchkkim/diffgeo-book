> 이 강의는 예전 opus 4 버전 시절에 만들었던 것이다. 현재 claude opus 5.5 의 능력을 이용해서 시각화 예제를 다듬고, 강의 내용을 살펴본 후 혹시 부족한 부분이 있으면 보강하는 작업을 하자.

수식 색 규칙·색 배정표·등장인물·대화 규칙·외형 설정은 **`docs/집필노트.md`** 가 기준(원문 인용 포함). 이 문서는 작업 순서만 다룬다.

### 기호 충돌 (규칙 3 이 필요한 실제 사례)
- `R`: 3장 구의 **반지름** / 7장 **리만 곡률** $R^i{}_{jkl}$ / 9장 **스칼라 곡률** $R$
- `∇`: 4~10장 **접속** / 12장 **그래디언트** $\nabla L$
- `F`: 3장 가우스 계량 성분 $E,F,G$ / 12장 **피셔 정보행렬**
- `p, q, r`: 1~9장 매니폴드의 **점** / 11장 **확률분포** / 3장 극좌표 $r$
- `G`: 3장 계량 성분 / 9장 아인슈타인 텐서 $G_{ij}$ / 중력상수 $G$
- `C`: 1장 $C^\infty$ (매끄러움) / 10장 **3차 텐서** $C_{ijk}$ / 9장 바일 텐서 $C_{ijkl}$

## 2. 색 배정표

`docs/집필노트.md` §1 참고 (초안 17색). 판단이 필요한 지점:
- 금색 `#e6ab02`(가우스 곡률)·`#bcbd22`(3차 텐서)·`#17becf`(곡선)는 흰 배경에서 대비가 약하다(2~2.5:1). 라이트 모드에서만 어두운 변형(`#b8860b`, `#9a9a1e`, `#0f9fb0`)으로 바꿔 보여 주는 안이 있다.
- 방향 벡터(파랑)와 대상 벡터(주황)를 나눈 이유: $\nabla_v W$, $R(u,v)W$ 에서 "어느 쪽으로 미분하나 vs 무엇을 미분하나"가 가장 헷갈리는 지점이라서.
- 피셔 정보 $F$ 를 계량과 같은 빨강으로 칠한다. 12장의 핵심 메시지인 "피셔 정보 = 계량"을 색으로도 보여 주려는 것이다.

## 3. 기술 설계

1. **`viz/shared/palette.js`** — 개념 키 → `{ hex, dark, label }`. 위젯은 이 모듈만 import (파일별 `const BLUE = …` 제거).
2. **빌드 치환 (`build.cjs`)** — KaTeX 출력의 `style="color:#d62728"` 을 `style="color:var(--c-metric,#d62728)"` 로 바꾸고, `style.css` 에 `[data-theme="dark"]` 용 `--c-*` 밝은 변형을 palette.js 에서 생성. 원고(.md)에는 규칙대로 hex 만 쓴다.
3. **위젯 수식 표시** — canvas monospace 대신 KaTeX 로 HTML 오버레이에 렌더(값이 바뀌면 문자열 재렌더). 본문과 같은 모양·같은 색.
4. **위젯 공통 틀** — 상단에 "조작하며 확인할 한 문장", 슬라이더 라벨은 해당 기호를 같은 색으로. 드래그 3D 회전(기존 원칙) 유지, ref 기반 고빈도 갱신 유지.
5. **정지 화면/검증** — Playwright(파이썬 설치 확인됨, 브라우저 바이너리 확인 필요)로 위젯 캡처해 직접 눈으로 확인. 수치는 파이썬으로 먼저 검증.

## 4. 장별 작업

순서는 장마다 **① 문장·구조 정리 → ② 수식 색·기호 표 → ③ 내용 보강(예제) → ④ 연습문제 + 함께 풀기 대화 → ⑤ 카툰 컷 → ⑥ 위젯 다듬기/추가**.

공통:
- 「시각화 아이디어」 절 → 「직접 움직여 보기」로 이름 변경, 기획 메모 불릿 삭제(좋은 비유는 본문으로 흡수).
- inline 에만 있던 핵심 식을 display 로 승격해 색·기호 표 적용.
- 장마다 **손 계산 예제 1~2개** 추가 (「따라 계산해 보기」 소절, 「정리」 뒤).

| 장 | 보강할 내용(예제·식) | 위젯 |
|---|---|---|
| 1 매니폴드 | 원 $S^1$ 을 두 차트로 덮고 전이함수 계산(각도 차트 두 개) | 기존: 다듬기 |
| 2 접선공간 | 구면 좌표에서 $\partial_\theta, \partial_\phi$ 계산, 곡선 속도를 기저로 분해 | 기존 + 곡선 속도 분해 |
| 3 계량 | 구면 계량 $ds^2$ display 승격, 위도선 길이 $2\pi R\sin\theta$ 계산 예제 | 기존(메르카토르) + 포앙카레 원판 "늘어나는 자" |
| 4 접속 | 극좌표 $\Gamma^r_{\theta\theta}=-r$, $\Gamma^\theta_{r\theta}=1/r$ 손 계산 | 기존 2개 다듬기 |
| 5 평행이동 | 위도선 따라 한 바퀴: $\Delta\theta = 2\pi(1-\cos\theta_0)$ 와 가우스-보네 확인 | 기존 + 수치 대조 |
| 6 측지선 | 구면 측지선 방정식을 대원이 만족함을 확인 | 기존 다듬기 |
| 7 곡률 | 구 $K=1/r^2$ 를 주곡률로, 원기둥 $K=0$ | 기존 다듬기 |
| 8 빼어난 정리 | 가우스 곡률의 계량 공식(직교 좌표계 $F=0$ 형태) display 추가 + 구에 적용 — 현재 display 수식 0개 | 기존 + 피자 접기 |
| 9 리치 | 리치·스칼라 곡률 정의 display, 구 $S^2$ 에서 $R=2/r^2$ | 기존 + 리치 흐름 수축 |
| 10 쌍대 접속 | 정규분포 족에서 e-좌표/m-좌표 예 | 기존 다듬기 |
| 11 발산 | 두 정규분포 KL 계산, 2차 전개 = 피셔 확인 | 기존 다듬기 |
| 12 자연 경사 | 피셔 정보 정의 display, 1차원 정규분포 $F$ 계산, 재매개변수화 불변 수치 확인 | 기존 다듬기 |

## 4-1. 연습문제와 함께 풀기

- 장 끝(「연결되는 세계들」 앞)에 **「연습문제」** 절: 3~4문제. 쉬운 확인 1~2 / 계산 1 / 킬러 1. 위 표의 손 계산 예제와 겹치지 않게 한다.
- 이어서 **「함께 풀어 보기」** 절: 선생님·김민준·이서연 대화. 규칙은 집필노트 §2 그대로.
  - 문제마다 두 학생이 *서로 다른 이유로* 틀리거나 한 명만 틀린다. 장별 오답 설계 예:
    - 4장: 민준 — "Γ 도 텐서니까 좌표 바꿔도 0 이면 계속 0" / 서연 — 극좌표 $\Gamma$ 부호는 맞췄지만 $r=0$ 에서 발산하는 의미를 놓침
    - 8장: 민준 — "원기둥은 휘어 보이니까 $K\neq0$" / 서연은 맞히지만 "왜 종이로 구를 못 싸는지"를 물리적으로 설명하지 못함
    - 12장: 민준 — PyTorch 로 돌려 보고 "학습률만 키우면 같다" / 서연 — $F^{-1}$ 이 대각이라 가정
  - 교정 뒤 비유 하나: 민준은 과제·보고서·조교, 서연은 수학 수업.
  - 대화 속 수식도 색 규칙을 따른다(display 는 기호 표 포함).
- 연습문제 답은 파이썬으로 검증.

## 5. 진행 방식

- 1장을 먼저 끝까지 해서 결과물(수식 형식·위젯 모양)을 확인받은 뒤, 나머지 장은 2~3장씩 병렬(서브에이전트)로 진행.
- 장마다 빌드 → 브라우저 캡처로 확인 → 보고. 커밋은 지시가 있을 때만.
- 예제 수치는 전부 파이썬으로 검증.
