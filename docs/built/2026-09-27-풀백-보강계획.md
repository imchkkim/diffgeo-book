## 1. 진단 — 교재에 「풀백」은 한 번도 나오지 않는다

`풀백`·`pullback`·`f^*` 는 원고 전체에서 0회. 대신 풀백의 **조각**이 이름 없이 흩어져 있다.

| 위치 | 있는 것 | 풀백 관점에서 빠진 것 |
|---|---|---|
| 2장 「여접벡터」 절 (`02-…md:216~248`) | 1-형식 = 눈금자, 그래디언트 성분이 화살표와 반대로 변함 | 「화살표는 앞으로, 눈금자는 뒤로」라는 방향 규칙의 *이유*가 없음 |
| 3장 「리만 계량」 절 (`03-…md:150~162`) | 구면 계량 $R^2(d\theta^2+\sin^2\theta\,d\phi^2)$ 을 **주어진 것**으로 제시 | 3차원 공간의 자를 구면으로 끌어와 *유도*하는 길이 없음 (대화록의 극좌표 $dr^2+r^2d\theta^2$ 유도와 같은 계산) |
| 12장 「피셔 정보행렬」 절 | 피셔 행렬 = 스코어의 공분산 | 피셔 행렬이 「분포 공간의 자를 매개변수 공간으로 끌어온 것」이라는 **출처**가 없음. 그래서 왜 재매개변수화에 불변인지가 식 조작으로만 보임 |
| 12장 「푸시포워드」 절 (`12-…md:188~255`) | $F_\theta = J^T F_\varphi J$, 푸시포워드 $f_*$ 정의 | ① 변환 규칙을 **미분동형사상(좌표 바꾸기)** 에만 적용 — 되돌릴 수 없는 사상 $\theta \mapsto p_\theta$ 는 다루지 않음. ② $J^T(\cdot)J$ 에 이름이 없음. ③ 방향 비대칭(왜 자는 뒤로만 오는가) 없음 |
| 12장 「ML에서: 노멀라이징 플로」 | $p_x = p_z\,\lvert\det\rvert^{-1}$ | 행렬식이 *왜* 붙는지(밀도 = 부피당 확률 = $n$-형식) 설명 없음. 「치환적분의 $dx = f'(t)dt$ 와 같은 일」이라는 연결 없음 |
| 11장 「ML에서: 신뢰 영역을 KL로 잰다」 | TRPO 의 KL 제약 → 피셔 2차 근사 | TRPO 목적함수가 **중요도 샘플링** 추정량이라는 점, 목적함수와 제약이 같은 뿌리(가중치의 분산)라는 점 없음 |
| 책 전체 | — | 과매개화된 신경망에서 피셔 행렬이 특이(역행렬 없음)해지는 이유, 가우스-뉴턴 $J^T H J$ 가 같은 꼴이라는 점 없음 |

**결론: 보강 필요.** 재료(야코비안, 여접벡터, 피셔 계량, 변환 규칙)는 모두 갖춰져 있으나, 그것들을 하나로 묶는 개념 「풀백」과 그 핵심 쓰임(되돌릴 수 없는 사상, 특이 계량, 밀도의 행렬식)이 빠져 있다.

## 2. 보강 방침

- **새 절 하나에 모은다 (SSOT).** 12장 「푸시포워드」 절 바로 뒤에 `## 풀백: 저쪽의 자를 이쪽으로 끌어오기` 를 신설한다. 푸시포워드(화살표를 앞으로) ↔ 풀백(자를 뒤로)이 짝으로 이어지는 자리다.
- 다른 장에는 **한두 문장의 복선/연결만** 둔다. 같은 설명을 여러 곳에 복사하지 않는다.
- 설명 언어는 대화록 2차 답변의 평이한 틀을 쓴다: **다이얼(매개변수) → 번역표(야코비안) → 저쪽 자로 재기**. 「야코비안으로 끌어온다」 같은 압축 표현은 이 세 걸음으로 풀어 쓴 뒤에만 쓴다.
- 대화록의 표현 중 **부정확하거나 과장된 것은 싣지 않는다**: 「K-FAC·TRPO·NPG 가 모두 같은 구조」(묶음이 거침), 「학습 궤적이 갇히는 특이점」(근거 서술 없음), 「가중치의 신뢰성은 풀백 계량이 잰다」는 2차 근사에서만 성립함을 반드시 명시.

## 3. 새 절 설계 — 12장 `## 풀백: 저쪽의 자를 이쪽으로 끌어오기`

절 안 순서는 `chapter-section-edit` 규칙(왜? → 역사 → 사례·장난감 예제 → 그림·위젯 → ML에서 → 문제).

### 3-1. 왜? (도입)
앞 절의 $F_\theta = J^T F_\varphi J$ 를 다시 불러와 질문을 던진다: 「$\varphi$ 도 $\theta$ 도 매개변수의 이름표일 뿐이라면, 피셔 계량이라는 자는 *원래 어디에* 있었나?」 → 답: 분포들의 공간 $P$ 에. 매개변수 모델은 사상 $\Theta \to P$ 이고, 이 사상은 되돌릴 수 없을 수도 있다(서로 다른 $\theta$ 가 같은 분포). 푸시포워드 절은 되돌릴 수 있는 사상만 다뤘으므로 여기서 한 걸음 넓힌다.

### 3-2. 역사 (선택)
짧게 1문단 후보: 엘리 카르탕(Élie Cartan)의 미분형식 — 형식은 사상을 따라 뒤로 끌어올 수 있다는 성질 덕분에 좌표 없이 적분·미분을 다룰 수 있게 됨. **넣을지 말지는 질문 Q3.**

### 3-3. 개념과 장난감 예제
1. **정의 세 줄** (풀백은 합성 하나로 시작한다)
   - 함수: $f^*h = h \circ f$ — 지도(M)의 점을 지구(N)로 보낸 뒤 그 자리 기온을 읽어 지도에 적는다.
   - 1-형식: $(f^*\omega)(v) = \omega(f_* v)$ — 화살표를 먼저 앞으로 밀고, 저쪽 눈금자로 잰다.
   - 계량: $(f^*g)(u,v) = g(f_*u, f_*v)$, 성분으로 $G = J^T g J$. 자는 화살표 **두 개**를 받으므로 번역표가 양쪽에 하나씩 붙는다(12장 문제 3 「계량은 두 번」과 같은 이야기).
2. **방향 비대칭의 이유** — 두 다이얼 설정이 같은 결과로 가면, 다이얼 쪽 값을 앞으로 밀 때는 「어느 값을 적나」 충돌이 나지만, 뒤로 끌어올 때는 충돌이 없다. 그래서 화살표는 앞으로, 자·눈금자·함수는 뒤로 온다.
3. **장난감 예제 ① 치환적분** — $\int g(x)\,dx = \int g(f(t))\,f'(t)\,dt$ 가 곧 $\int_N \omega = \int_M f^*\omega$. 학부 1학년의 「$dx$ 를 $f'(t)dt$ 로 바꿔 쓴다」가 풀백의 계산 규칙.
4. **장난감 예제 ② 극좌표 계량 (따라 계산해 보기)** — $f(r,\theta) = (r\cos\theta, r\sin\theta)$, $f^*dx$, $f^*dy$ 를 구해 제곱해 더하면 $dr^2 + r^2d\theta^2$. 숫자 확인: 각도 다이얼 0.01 을 $r=1$ 에서는 0.01, $r=10$ 에서는 0.1 만큼 실제로 움직인다. $r^2$ 은 외울 공식이 아니라 번역표 숫자의 제곱. (3장 구면 계량도 같은 방식으로 나온다는 한 줄 연결.)
5. **풀백이 자가 되지 못하는 곳** — $f^*g$ 가 진짜 계량(0 아닌 화살표에 늘 양수)이려면 번역표가 어떤 화살표도 0으로 보내지 않아야 한다(몰입, immersion). 번역표가 납작해지는 방향은 「길이 0」으로 판정된다.

### 3-4. 그림·위젯 — 새 위젯 `ch12-pullback` (질문 Q2)
「다이얼과 번역표」 위젯. 왼쪽 = 다이얼 공간 $(\theta_1,\theta_2)$, 오른쪽 = 결과 공간. 결과 공간의 단위원(자)을 번역표로 끌어와 다이얼 공간에 **타원**으로 그린다.
- 사상 선택: (a) 극좌표 — 원점에 가까울수록 타원이 $\theta$ 방향으로 길어짐, (b) 2-로짓 소프트맥스 $(z_1,z_2) \mapsto p$ — 타원이 한 방향으로 **무한히 긴 띠**가 됨(특이 계량).
- 다이얼 점을 끌면 번역표 $J$ 와 $G = J^T g J$ 성분이 수식 색 그대로 실시간 표시 (메모리: 시각화-수식 연결 원칙).
- 기존 `ch12-natgrad.jsx` / `viz/shared` 의 유틸 재사용 여부는 구현 전 검사.

### 3-5. ML에서 (절 끝 소절 하나, 항목 4개 이내)
1. **피셔 행렬 = 풀백 계량** — 이산 분포 공간의 자 $\sum_a dp_a^2/p_a$ 를 $\theta \mapsto p_\theta$ 로 끌어오면 $F_{ij} = \sum_a \frac{1}{p_a}\frac{\partial p_a}{\partial\theta^i}\frac{\partial p_a}{\partial\theta^j}$, 곧 앞 절의 스코어 공분산과 같다(한 줄 확인). 자연 경사가 좌표에 안 휘둘리는 이유가 「자는 $P$ 에 있고 매개변수는 이름표」라는 한 문장으로 정리됨.
2. **과매개화와 특이 피셔 행렬** — 서로 다른 가중치가 같은 함수를 만드는 방향은 번역표가 0으로 보내므로 피셔 행렬에 역행렬이 없다. 실무의 감쇠항 $F + \lambda I$ 와 유사역행렬이 이 지점을 우회하는 처방.
3. **가우스-뉴턴 행렬** — 출력 쪽 손실의 곡률 $H_z$ 를 네트워크 번역표로 끌어온 $J^T H_z J$. 지수족 손실(교차 엔트로피 등)에서는 피셔 행렬과 같다.
4. **밀도의 풀백과 행렬식** — 밀도는 「부피당 확률」이라 함수처럼 합성만 해서는 안 되고 부피 배율 $\lvert\det J\rvert$ 가 붙는다. 노멀라이징 플로의 $\log\lvert\det J\rvert$ 항이 이것이며, 치환적분의 $f'(t)$ 자리에 행렬식이 온 것뿐. **계량의 풀백($J^T g J$)과 밀도의 풀백($\lvert\det J\rvert$)은 다른 연산**임을 표로 대비.

### 3-6. 연습문제 (`textbook-exercise-ladder` 세 계단 + 함께 풀기)
- **문제 4 (워밍업, 일상 비유)** — 환율표로 달러 가격표를 원화 가격표로 옮기는 일은 되는데, 두 나라 물건이 같은 원화 값으로 겹칠 때 거꾸로 옮기면 무엇이 막히나? → 방향 비대칭.
- **문제 5 (수학)** — 3차원 공간의 자 $dx^2+dy^2+dz^2$ 를 구면좌표 사상으로 끌어와 3장의 구면 계량을 유도하라. (3장에서 주어진 것으로 받아들였던 식을 다른 각도에서 재확인.)
- **문제 6 (ML)** — 두 로짓 소프트맥스 베르누이 모델 $(z_1, z_2) \mapsto p = \sigma(z_1 - z_2)$ 의 피셔 행렬을 $J^T g J$ 로 구하고, 행렬식이 0임을 보이고, 길이 0 방향 $(1,1)$ 의 뜻을 말하라. → 과매개화 특이성의 최소 모형.
- 함께 풀기: 김민준이 문제 6 에서 $J$ 를 $1\times 2$ 로 잡아 $J J^T$ 를 계산(스칼라가 나옴)하는 실수 → 이서연이 「자는 다이얼 쪽에 생겨야 하니 결과가 $2\times2$」로 바로잡음. 끝에 「아까 환율 문제랑 같네」 대사로 계단을 잇는다.
- 기존 12장 문제 번호(1~3)는 유지, 새 문제는 4~6.

### 3-7. 장 마무리 갱신

## 5. 색·낱말

- 새 기호 $f^*$ (풀백), $f_*$ (푸시포워드, 이미 있음), $H_z$ (출력 쪽 곡률): 집필노트 규칙에 따라 Claude 가 배정하고 색 배정표/절별 보조색 표에 기록. 야코비안 $J$ 는 기존 `#964079` 유지.
- 낱말: 「끌어오다」= pullback 한 뜻으로만. 「사상」은 12장 미분동형사상 정의 불릿에 이미 풀이가 있음. 「몰입(immersion)」은 첫 등장에 풀이 + 사례. 집필노트 낱말 표에 「끌어오다 / 밀어내다」 추가.

## 7. 결정이 필요한 것

- **Q1. 중요도 샘플링(대화록 3차 답변)을 넣을 범위.** (a) 11장 TRPO 소절에 3~4문장: 「TRPO 목적함수는 중요도 가중치 $\pi_\theta/\pi_\text{old}$ 를 쓴 추정량이고, 가중치의 분산 $\chi^2 \approx \Delta\theta^T F \Delta\theta$ 가 KL 제약과 같은 자로 재진다」 — **추천**. (b) 12장 새 절 ML 소절에 한 항목으로 추가(가중치 = 밀도의 비라 행렬식이 약분되는 0-형식). (c) 둘 다. (d) 넣지 않음 — 이 책은 강화학습 책이 아니므로.
- **Q2. 새 위젯을 만들지.** 추천은 만든다(풀백의 핵심이 「자가 찌그러진 타원으로 끌려온다」는 그림이라). 만들지 않으면 정적 그림 1장으로 대체.
- **Q3. 역사 소절(카르탕)을 넣을지.** 추천은 넣지 않음 — 12장에는 이미 아마리 역사 소절이 있고, 풀백의 역사는 인물 서사가 약하다.
